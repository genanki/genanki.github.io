# 项目示例图片目录

本目录是网页工作台的**项目素材文件夹**。向这里提交 JPG / PNG / WebP 图片以后，把图片的完整文件名加入 `index.json`，例如：

```json
["cat-original.jpg", "pet-cartoon.png", "logo.webp"]
```

刷新工作台，侧栏“GitHub 项目内置素材”下拉框就能选择并处理这些图片。

请注意：仓库是公开的，所以**放进本文件夹的照片会对所有人公开**；包含个人隐私或版权疑虑的图片请使用网页里的本地“选择照片”或“选择整个文件夹”，它们只在浏览器中处理，不会自动提交到 GitHub。

当前目录没有预装用户照片，避免未经明确确认就公开上传原图。
