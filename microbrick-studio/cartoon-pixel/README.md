# 卡通分区 · 像素填色工作台

**在线入口**：https://genanki.github.io/microbrick-studio/cartoon-pixel/

## 功能

1. 导入本机图片（JPG/PNG/WebP）或批量导入图片文件夹，左侧可以逐个点击查看；拖放也支持。
2. 也可从仓库 `samples/` 目录选择已登记的素材（见 `samples/README.md`）。
3. 原照片、**卡通减色分区图**、**正方形像素填色格稿**同时显示。
4. 默认 **12 色 + 大色块合并 75% + 细轮廓 + 4 格以下碎块清理**；可调整 4—24 色、卡通强度、描边、小块清除。
5. 横向 30/50/70 格预设或自选 n×k，保持原始纵横比时纵向自动取整。**每个积木格都是正方形**，原图不会被拉伸。
6. 选择色板后在格子画布涂改或擦除，支持撤销。
7. 导出 PNG 填色图、CSV 各色颗粒采购数量、JSON 可回读工程稿。

## 数据隐私与模型说明

本网页纯静态部署于 GitHub Pages，照片处理在浏览器本地进行，**用户导入的原始照片不会自动上传 GitHub**。如果用户希望图片长期保存在项目素材目录中，必须明确自行或授权提交到公开 GitHub 仓库。

当前处理引擎是传统的边缘保留平滑、色彩聚类、相邻色块合并、连通域清理及像素轮廓增强，并**非真正的 AI 照片转动漫模型**。这是有意将“分区填色”与“AI 绘图”拆开，避免把简单缩小图片说成智能卡通重绘；更好的语义卡通化可由审核后的卡通母图输入本工具。

## 结构

- `index.html`：网页 UI 和 CSS
- `engine.js`：卡通分区与方格颜色映射引擎
- `app.js`：文件/文件夹导入、预览、修色、导出
- `samples/`：可选的 GitHub 已提交图片素材仓库
